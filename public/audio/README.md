# Audio Assets

This directory contains starter voice and educational audio assets for Foxwords.

All default audio files were recorded and voiced by Tim Dobson and are licensed under the Creative Commons Attribution-ShareAlike 3.0 Unported License (CC-BY-SA-3.0). See `CONTENT-LICENSE` and `docs/content-manifest.md` for full licensing details.

## Structure

- `phonemes/` — individual phoneme pronunciation recordings (`ae.webm`, `ah.webm`, etc.)
- `letter-names/` — alphabet letter name recordings (`a.webm`, `b.webm`, etc.)
- `words/` — spoken words corresponding to curriculum items (`cat.webm`, `dog.webm`, etc.)
- `numbers/` — spoken numbers for counting games (`1.webm`, `2.webm`, etc.)
- `plurals/` — spoken plural nouns (`teddies.webm`, `foxes.webm`, etc.)
- `clock/` — spoken clock time targets and phrases (`three-oclock.webm`, etc.)

Curriculum voice recording can be accessed at `/record` when running locally. In the deployed Foxwords app, parents can record custom audio for their child via the parent portal.
