# Foxwords Pen.dev & Accessibility Design Checklist

- [x] High-contrast, dyslexia-friendly typography for letters and numbers.
- [x] Generous touch targets (minimum 48×48px on mobile, 60×60px on tablet).
- [x] Explicit visual distinction between letter sounds (phonics) and letter names.
- [x] Zero-clutter, toddler-friendly keypad on `/join` with ambiguous characters (`O`, `0`, `I`, `1`) excluded.
- [x] Clear badge indicator when family voice is active versus Tim's default voice.
- [x] Non-blocking offline/reconnecting banner.
- [x] Accessible SVG clock face with distinct hour and minute spade hands.
- [x] Clean, password-free parent interface focused on high reliability.
