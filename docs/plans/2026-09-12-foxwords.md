# Foxwords Implementation Plan

> **For agentic workers:** This plan is structured for workflow orchestration. Tasks are labelled with agent types (`build-agent` / `review-agent` / `qa-agent`). Build tasks use `isolation: worktree`. Review tasks follow every 1-3 build tasks. QA gates every deploy.
>
> **Execution:** Use `superpowers:subagent-driven-development` for a small sequential run, or drop the phases directly into a Workflow script's `pipeline()`/`parallel()` calls for the recommended multi-agent run. Sonnet builders write code, Haiku researchers perform read-only reconnaissance, and Opus checkers review and verify.
>
> Steps use checkbox (`- [ ]`) syntax for tracking. All code, test, lint, build, and deployment commands use the repository's low-priority wrapper: `scripts/low-priority.sh` (`nice -n 19 ionice -c 2 -n 7`).

**Goal:** Turn the current single-user Letter Trail prototype into Foxwords, a personalised early-learning application deployed as one Cloudflare Worker with D1, R2, AWS SES magic-link parent access, no-login child play links, friendly family codes, and a fully tested responsive experience.

**Architecture:** Replace the current static Pages export with a Next.js App Router application built by OpenNext and deployed to Cloudflare Workers. Route handlers use Cloudflare D1 for account/profile metadata and R2 for private family media; a small Web Crypto AWS Signature V4 client sends magic-link mail through SES without adding the AWS SDK to the Worker bundle. The existing games remain reusable, but receive a profile context that merges the bundled Tim-voiced curriculum with family-specific words, photos, and recordings.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Mantine, Cloudflare Workers/OpenNext, D1, R2, Web Crypto, AWS SES Query API, Jest + Testing Library, Playwright, curl + jq, Biome, GitHub Actions-ready scripts.

**Codebases affected:** `foxwords` (the current `genericise-and-github` worktree; no second application repository).

## 0. Execution rules and dependencies

### Agent allocation

- **Haiku researchers (`Explore`, read-only):** investigate current Cloudflare/OpenNext free-tier limits, reference projects, SES API/IAM details, browser media support, and the existing UI/data surface. Researchers return findings with paths, commands, and links; they do not edit files or create external resources.
- **Sonnet builders (`build-agent`, `isolation: worktree`):** implement one bite-sized task at a time, write the failing test first, run the test, implement the smallest change, run the applicable quality gates, and commit before exiting.
- **Opus checkers (`review-agent`, read-only):** adversarially try to refute each build chunk against the design, security requirements, API contract, responsive UI contract, and tests. They do not merely report that files look reasonable.
- **Opus QA (`qa-agent`, read-only):** run the five-layer gauntlet after every dev deployment: Jest, curl, Playwright, Chrome MCP, and D1/R2 queries.

### Low-priority command wrapper

The first foundation task creates this executable wrapper and all later commands use it:

```bash
#!/usr/bin/env bash
set -euo pipefail
exec nice -n 19 ionice -c 2 -n 7 "$@"
```

`ionice -c 2 -n 7` is the lowest-priority best-effort class and is intentionally not the idle class. The wrapper is used for Node, Yarn, Biome, Jest, Next/OpenNext, Wrangler, curl, jq, and Playwright processes. External browser inspection and Cloudflare/AWS API calls are not CPU-heavy, but their local CLI processes are still launched through the wrapper where possible.

```sql
CREATE TABLE IF NOT EXISTS users (
  id TEXT PRIMARY KEY NOT NULL,
  email TEXT NOT NULL UNIQUE,
  stripe_customer_id TEXT,
  subscription_status TEXT NOT NULL DEFAULT 'plus',
  created_at INTEGER NOT NULL,

  used_at INTEGER,
  created_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS sessions (
  session_hash TEXT PRIMARY KEY NOT NULL,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  expires_at INTEGER NOT NULL,
  created_at INTEGER NOT NULL,
  last_seen_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS child_profiles (
  id TEXT PRIMARY KEY NOT NULL,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  child_name TEXT NOT NULL,
  play_token_hash TEXT NOT NULL UNIQUE,
  play_code TEXT NOT NULL UNIQUE,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS custom_words (
  id TEXT PRIMARY KEY NOT NULL,
  profile_id TEXT NOT NULL REFERENCES child_profiles(id) ON DELETE CASCADE,
  word TEXT NOT NULL,
  category TEXT NOT NULL CHECK (category IN ('vip', 'family', 'pet', 'toy', 'custom')),
  prompt_label TEXT NOT NULL,
  prompt_emoji TEXT,
  photo_asset_id TEXT,
  audio_asset_id TEXT,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS media_assets (
  id TEXT PRIMARY KEY NOT NULL,
  profile_id TEXT NOT NULL REFERENCES child_profiles(id) ON DELETE CASCADE,
  r2_key TEXT NOT NULL UNIQUE,
  kind TEXT NOT NULL CHECK (kind IN ('photo', 'word-audio', 'system-audio')),
  content_type TEXT NOT NULL,
  byte_size INTEGER NOT NULL,
  created_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS audio_overrides (
  id TEXT PRIMARY KEY NOT NULL,
  profile_id TEXT NOT NULL REFERENCES child_profiles(id) ON DELETE CASCADE,
  clip_key TEXT NOT NULL,
  asset_id TEXT NOT NULL REFERENCES media_assets(id) ON DELETE CASCADE,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  UNIQUE(profile_id, clip_key)
);

CREATE TABLE IF NOT EXISTS rate_limits (
  bucket TEXT PRIMARY KEY NOT NULL,
  window_started_at INTEGER NOT NULL,
  request_count INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_auth_tokens_user ON auth_tokens(user_id);
CREATE INDEX IF NOT EXISTS idx_sessions_user ON sessions(user_id);
CREATE INDEX IF NOT EXISTS idx_profiles_user ON child_profiles(user_id);
CREATE INDEX IF NOT EXISTS idx_words_profile ON custom_words(profile_id);
CREATE INDEX IF NOT EXISTS idx_assets_profile ON media_assets(profile_id);
```
